System Requirements & Setup Docs

Ensure your hardware and operating environment meet recommended specifications for peak Tally Prime performance.

Tally Prime Desktop Requirements

✓
OS: 64-bit Windows 10, Windows 11, or Windows Server 2019/2022.
✓
Processor: Intel Core i3 8th Gen / AMD Ryzen 3 or higher.
✓
RAM: 8 GB minimum (16 GB recommended for multi-user server).
✓
Disk: Solid State Drive (SSD) with at least 500 MB free for app and data.

Tally on Cloud Requirements

✓
Devices Supported: Windows PC, Apple Mac, iPad, Android Tablets.
✓
Internet Connection: Stable broadband connection (2 Mbps or higher per user).
✓
Printer Compatibility: Supports all local USB, Network, and Wireless printers.
✓
Zero Local Hardware Maintenance: Managed server updates by Das Enterprises.
